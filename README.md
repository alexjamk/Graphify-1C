# Graphify-1C

Graphify-1C строит единый граф исходников конфигурации 1С и её расширений. Он помогает находить объекты и методы, переходить по вызовам, чтениям запросов, записям регистров и связям расширений.

**[Пошаговая инструкция для ChatGPT, Codex, Claude Code и VS Code](docs/1c/QUICKSTART_AGENTS.md)** — установка, построение графа, первые запросы и готовые `AGENTS.md`, `CLAUDE.md` и инструкции Copilot.

Проект основан на [Graphify](https://github.com/Graphify-Labs/graphify). Исходная документация сохранена в [README.upstream.md](README.upstream.md). Лицензии и уведомления авторов сохранены в репозитории.

## Возможности

- Автоматическое обнаружение основной конфигурации в `src/cf` и расширений в `src/cfe/*`.
- Общий граф с сохранением происхождения каждого узла: основная конфигурация или конкретное расширение.
- Связи `EXTENDS`, `BEFORE`, `AFTER`, `INSTEAD`, `CHANGE_CONTROL`, вызовы методов, чтения таблиц, записи регистров и ссылки на метаданные.
- Поиск и запросы к сохранённому графу через команды `explain`, `path` и `query`.
- Локальный просмотр большого графа через SQLite: обзор типов, поиск, группировка связей и загрузка по 20 связей.

## Установка и запуск

Требуются Python 3.10+, Git и `pipx`. Форк устанавливается в отдельное окружение, а его команда получает имя `graphify-1c`:

```powershell
python -m pip install --user pipx
python -m pipx ensurepath
git config --global core.longpaths true # Windows: для сборки парсера BSL
python -m pipx install --suffix=-1c 'graphifyy[onec] @ git+https://github.com/alexjamk/Graphify-1C.git'
graphify-1c analyze ./src --out graphify-out/graph.json --html graphify-out/graph.html
```

Откройте новый терминал после `ensurepath`. Если оригинальный `graphify` уже установлен, он сохранится как отдельная команда. Подробности установки и ограничения парсера BSL — в [пошаговой инструкции](docs/1c/QUICKSTART_AGENTS.md).

Для большого графа запустите локальный просмотрщик и откройте адрес, который он напечатает:

```powershell
graphify-1c serve graphify-out/graph.html
```

Пример структуры проекта:

```text
src/
├── cf/                 # основная конфигурация
└── cfe/
    ├── РасширениеА/
    └── РасширениеБ/
```

## Данные и ограничения

В репозитории нет выгрузок конфигураций, копий баз и построенных графов. Результаты анализа записываются локально в `graphify-out/` и исключены из Git. Встроенные тесты и небольшие исходные фикстуры включены.

Восстановление динамических вызовов и составных текстов запросов может быть неполным. Полная инкрементальная индексация пока не реализована; текущие ограничения перечислены в [статусе проекта](docs/1c/IMPLEMENTATION_STATUS.md).
