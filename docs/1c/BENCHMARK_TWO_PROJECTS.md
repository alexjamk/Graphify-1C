# Проверка поиска на двух конфигурациях

Проверка выполнена на локальных файловых выгрузках с двумя выбранными расширениями в каждой. Выгрузки, пути к ним, названия расширений и построенные графы не публикуются. Первый граф содержит 1 515 802 узла и 3 408 538 связей; второй — 552 278 узлов и 1 223 778 связей.

Для десяти заранее записанных вопросов о документах `ПоступлениеБезналичныхДенежныхСредств` и `ЗаказКлиента` сравнивались ответы из готового SQLite-индекса и прямой поиск `rg` по XML/BSL. В обеих конфигурациях совпали 10 из 10 проверенных ответов. Каждый запрос выполнялся семь раз; ниже сумма медиан по десяти вопросам. Время построения графа не включено.

| Показатель | Крупная ERP-конфигурация | «Управление торговлей» 11.5.27.52 |
| --- | ---: | ---: |
| Готовый граф SQLite | 2,550 мс | 8,235 мс |
| Прямой поиск `rg` | 522,937 мс | 423,508 мс |
| Текст ответов графа, `o200k_base` | 339 токенов | 359 токенов |
| Текст результатов `rg`, `o200k_base` | 1000 токенов | 1073 токена |

Токены измеряют **только выдачу инструментов**. Они не включают запросы агента, чтение нужных исходников, рассуждения и проверки. Это не замер суммарной стоимости работы агента. Вопросы выбраны вручную и охватывают лишь часть типов связей; совпадение ответов не доказывает полноту графа для всех задач.

Отдельно проверен кэш разбора BSL на синтетической конфигурации из 300 документов, заполненных реальными BSL-фрагментами. Повторная экстракция заняла 1,005 с против 2,958 с при первом прогоне. После изменения одного модуля повторно использованы 299 записей кэша, одна обработана заново; результат совпал с анализом без кэша. Этот замер **не включает** запись JSON и SQLite, поэтому его нельзя считать ускорением всей команды `update`.

Воспроизведение на собственном проекте: `python -m scripts.benchmark_onec_documents --src ./src --database graphify-out/graph.sqlite --extension Расширение1 --extension Расширение2 --repeats 7`. Для объёма выдачи: `python -m scripts.measure_onec_document_payload` с теми же `--src`, `--database` и `--extension`; потребуется `tiktoken`. Для кэша: `python -m scripts.benchmark_onec_cache --synthetic 300 --samples <каталог-BSL>`.
