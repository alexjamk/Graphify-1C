# ADR 004: представление 1С поверх HTML-viewer Graphify

Статус: принято, 18 сентября 2026 года.

## Контекст

Стандартный HTML-viewer Graphify уже предоставляет интерактивный граф, поиск, карточку узла и фильтр сообществ. Для проекта 1С требуются дополнительные фильтры по происхождению, типам узлов и связей, а также локальный обход больших графов.

## Решение

`graphify.onec.viewer.write_onec_html()` использует штатный экспортёр Graphify для графа до 5000 узлов. Для большего графа создаются маленькая HTML-оболочка, соседний SQLite-индекс и короткий JSON обзора. На стартовой странице показан агрегированный граф типов объектов; щелчок по группе открывает список отдельных объектов. После выбора объекта связи группируются по отношению и направлению, а выбранная группа загружается страницами по 20 связей. Счётчик показывает полное число связей в группе; фильтры источника и типа узла применяются на сервере. Кнопка «Обзор графа» возвращает к стартовой схеме. Локальный сервер `graphify-1c serve graphify-out/graph.html` слушает только `127.0.0.1` и выдаёт поиск (до 30 результатов), группы и страницы соседей. Для глубины 2–3 остаётся ограниченный обход (не более 300 узлов и 800 связей). Браузер не загружает полный JSON или SQLite-файл и не строит индексы по всем узлам и связям. HTML открывается по адресу, который печатает локальный сервер.

## Последствия

Малый HTML по-прежнему открывается без сервера. Большой просмотрщик требует локальный сервер, но не требует установки отдельной БД или внешней службы. Он сохраняет фильтры по расширению, типу узла и типу связи. Физические узлы базы и расширений остаются отдельными; порядок исполнения расширений не выводится без подтверждённых данных. На «Управление торговлей» 11.5.27.52 после исправления записи регистра: 552 278 узлов, 1 223 778 связей, HTML около 26 КБ, обзор 3 028 байт, SQLite 1 283 936 256 байт. В браузере проверены стартовый обзор, поиск, выбор узла и переход со страницы 1–20 на 21–40 для роли с 2407 связями `grants`.
