# Готовый запрос для ChatGPT

Если Graphify-1C ещё не установлен, сначала дайте агенту
[одну ссылку для полной настройки](../SETUP_BY_AGENT.md). Для каждого нового проекта
откройте именно его корень в ChatGPT Desktop с доступом к терминалу; индекс
этого проекта должен находиться в его `graphify-out/`. Скопируйте текст ниже в чат:

> Ты работаешь в корне проекта 1С. Прочитай только небольшой `graphify-out/.graphify_onec.json`, если он есть: `extensions` хранит явно переданные `--extension`, а SQLite-индекс находится рядом с файлом `html` с суффиксом `.sqlite`. Пустой `extensions` при `root=src` означает автоматическое обнаружение всех корректных `src/cfe/*`, а не отсутствие расширений. Если манифеста нет, `analyze ./src` включит все корректные непосредственные расширения; для выбранной части используй `analyze ./src/cf` с отдельным `--extension` для каждого. Граф включает метаданные, BSL и происхождение узлов. Для моего вопроса сначала найди узел через `graphify-1c index search '<индекс>' '<имя>'`, выбери точный ID по типу и происхождению, затем запроси нужные связи через `graphify-1c index neighbors '<индекс>' '<точный id>' --direction in --relation calls --limit 10 --offset 0` (замени `calls` нужным типом связи). Для «всех мест использования» переходи к `--offset 10`, `20` и далее до пустого ответа и проверь подходящие отношения (`calls`, `references`, `type_reference`, `query_reads`, `writes`, `EXTENDS`, перехваты). Проверь важные выводы по `source_file` и `start_line` в XML/BSL. Не загружай весь JSON-граф. Если индекс отсутствует при существующем манифесте, выполни `graphify-1c update .`; без манифеста создай граф командой `graphify-1c analyze ./src --out graphify-out/graph.json --html graphify-out/graph.html`, если пользователь не выбрал часть расширений. После изменений выполни `graphify-1c update .`. Если SQLite не появился, выполни `graphify-1c index build graphify-out/graph.json graphify-out/graph.sqlite`.

Если ChatGPT не имеет доступа к терминалу, выполните `search` и `neighbors` сами и приложите их небольшой вывод с вопросом. Обычный веб-чат не видит локальный `src` автоматически.
