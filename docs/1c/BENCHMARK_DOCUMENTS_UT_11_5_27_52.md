# Время ответа на 10 вопросов по документам «Управление торговлей» 11.5.27.52

Дата: 18 сентября 2026 года. Измерены вопросы из [проверки ответов](EVALUATION_DOCUMENTS_UT_11_5_27_52.md) по документам `ПоступлениеБезналичныхДенежныхСредств` и `ЗаказКлиента`. Состав проекта: основная конфигурация и только расширения `Расширение 1` и `Расширение 2`.

Для графа использован уже построенный индекс `graphify-out/ut-11-5-27-52.sqlite`. Для исходников использован `rg` по известным каталогам и файлам той же выгрузки. Каждый запрос выполнен 7 раз; таблица содержит медиану времени выполнения, включая открытие SQLite либо запуск `rg`. Файловый кэш ОС уже прогрет. По 9 вопросам с одинаковым ответом сумма медиан составляет **1,914 мс** для готового графа и **242,547 мс** для поиска по исходникам (примерно **127 раз**). Это время автоматического получения фактов, а не время анализа человеком. Вопрос 8 исключён из сравнения скорости полезного ответа: граф возвращает пустой результат, потому что пока не распознаёт запись через переменную `ЗаписьРегистра`; исходники подтверждают запись. Если сложить все 10 замеров без учёта точности, получится 2,103 мс против 250,332 мс, но такой показатель вводил бы в заблуждение.

Предварительное построение графа **не входит** в эти времена. Измеренное ранее построение SQLite индекса из готового JSON заняло 47,76 с; получение самого JSON требует отдельного полного анализа и здесь не замерялось. Поэтому эти цифры показывают выгоду повторных запросов по уже построенному графу. Для разового вопроса по известному файлу поиск по исходникам может быть быстрее с учётом подготовки графа. Поиск `rg` в вопросе 7 просматривает каталог регистров, поэтому он заметно дороже остальных запросов по конкретным файлам.
