# Сколько контекста занимают результаты графа и поиска

Дата: 18 сентября 2026 года. Корпус и 10 вопросов те же, что в [сравнении времени](BENCHMARK_DOCUMENTS_UT_11_5_27_52.md). Это **замер токенов в тексте результатов инструментов**, а не статистика токенов независимых прогонов ассистента. Использован токенизатор `o200k_base` из `tiktoken`; фактическая токенизация работающей модели может отличаться.

Для графа сериализованы минимальные строки фактов, возвращаемые SQLite. Для исходников взят текст ответа `rg`: имена найденных XML-файлов, директивы перехватов с путями и строками, фрагменты двух процедур проведения, определение метода менеджера, строка записи регистра и фрагменты XML реквизитов. В вопросах 5–6 фрагмент обрезан на `КонецПроцедуры`. Формат вывода может влиять на результат; скрипт и [сырые числа](PAYLOAD_DOCUMENTS_UT_11_5_27_52.json) позволяют это проверить.

| 9 | 16 | 152 | Да |

По девяти вопросам с одинаковым ответом результаты графа заняли **344 токена**, результаты поиска — **930 токенов**: на **586 токенов, или 63% меньше**. Вопрос 8 исключён: нулевой вывод графа там означает пропущенную запись, а не экономию на правильном ответе.

Этот показатель не равен экономии общего лимита Codex. Не посчитаны текст запросов и вызовов инструментов, служебное обрамление ответов, мои рассуждения, повторная проверка фактов и стоимость неудачных попыток. Для вопроса 4 оба пустых вывода имеют нулевой размер, хотя вызовы инструментов тоже расходуют контекст. Предварительная индексация графа расходует локальное время и диск; её стоимость токенов зависит от того, выполняет ли её агент и какие сообщения видит. Для измерения **полного** расхода нужны два независимых прогона одинаковых задач с одинаковыми настройками модели и записью `input_tokens`, `output_tokens`, кэшированных токенов и точности ответов. По имеющимся данным такую экономию в процентах утверждать нельзя.

Воспроизведение:

```powershell
python -m pip install tiktoken
$env:PYTHONIOENCODING = 'utf-8'
python scripts/measure_onec_document_payload.py --src './src' --database graphify-out/ut-11-5-27-52.sqlite
```
